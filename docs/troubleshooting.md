# Troubleshooting

## Dataset not found

Run Jupyter from the repository root and keep `AirPassengers.csv` beside the notebook.

## TensorFlow installation failure

Check the Python version and platform support for the selected TensorFlow release. ARIMA analysis can be run independently of the neural-network cells.

## Different metrics

Check split dates, scaling, inverse transformations, random seeds, and whether stale notebook outputs were used.
